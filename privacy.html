Privacy Policy

Last updated: September 26, 2026

1. Overview

Ball Escape is a desktop application that generates video files locally. This policy describes the information that may be involved when optional online integrations are used.

2. Data processed by the desktop application

The video generator can use local settings such as generation parameters, output paths and other information required to create a video. Generated video files are stored on the user's computer unless the user chooses to send or publish them elsewhere.

3. TikTok authorization and publishing

When a user connects Ball Escape to TikTok, the user is redirected through TikTok's authorization flow. Depending on the permissions granted and the integration used, Ball Escape may receive authorization information needed to make requests to TikTok on the user's behalf. Generated video content and related publishing information may be transmitted to TikTok when the user starts a publishing operation.

4. Third-party processing

TikTok may process account information, uploaded content and API requests under TikTok's own privacy policies and terms. Users should review those documents before authorizing the integration.

5. Data sharing

Ball Escape is not designed to sell personal information. The application only sends information to third-party services when required for a feature that the user has chosen to use, such as an authorized publishing request.

6. Data retention

Generated videos are normally retained locally according to the user's own file management. Any data retained by a third-party service is subject to that service's policies.

7. Security

Users should protect their computer, credentials and API tokens. Do not publish access tokens or other secrets in public source code or repositories.

8. Changes to this policy

This policy may be updated when the application or its integrations change. The "Last updated" date will be changed when a new version is published.
